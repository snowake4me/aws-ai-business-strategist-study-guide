**Always record the confidence signal.** On Tutorials Dojo that is *flagged for
review*, since TD has no confidence tag. An unflagged miss is a blind miss and is the
number that matters most; raw score lags real learning.

**Capture the flagged list before submitting.** TD's post-exam review only offers a
combined *Skipped + Marked for Review* filter, and its per-question timer drops to
0:00 on some questions (probably when the exam is paused), so post-hoc handling data
is unreliable. Screenshot the flag state before submit, and note any pauses.

## Test-taking protocol (Billy's, standing)

- **Never skip.** Every question gets the best answer available in the moment.
  Skipping wrecks the progress-versus-clock meter and leaves questions exposed to a
  rushed end.
- **Flag when particularly uncertain.** The flag is the confidence signal this repo
  measures against; attempt 1 showed it is reliable (0 unflagged misses).
- **Default is submit, not revisit.** After two-plus hours the tank is empty and
  second-guessing an initial best answer is a net loss. A revisit happens only when a
  *later question* produced a genuine new insight about a flagged one, which is rare
  (a couple of times in a career). Then go straight to that question, apply the
  insight, and stop.
- So the first answer is the answer. Every drill in this repo therefore targets the
  **first read**: find the fact in the stem, eliminate on it, commit.
